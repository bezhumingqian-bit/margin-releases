# Margin · 写作工作室

本地优先的 AI 辅助小说创作客户端。这个公开仓库只用于分发安装包、安装说明与反馈，不存放个人作品、小说原文库、API Key 或私有源码仓库。

## 下载 Mac 测试版

**[前往下载页面](https://github.com/bezhumingqian-bit/margin-releases/releases/tag/v0.1.14-mac-preview)**

选择 `Margin-0.1.14-macOS-arm64.dmg`，不要下载 `Source code`。当前支持 **Apple Silicon（M 系列芯片）Mac、macOS 13 或更新版本**；尚无 Intel Mac / Windows 包。

打开 DMG，将 **Margin.app** 拖到 **Applications（应用程序）**，然后从“应用程序”启动。

### 首次打开的重要提示

这是早期预览版，**尚无 Apple Developer ID 签名和公证**，不是无警告安装的正式发行版。系统可能阻止直接打开。

核实下载来源后，可按 [Apple 官方指引](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”查看针对 Margin 的“仍要打开”选项。如果提示恶意软件、应用损坏或没有允许选项，请停止并反馈；不要全局关闭系统安全保护。

更详细的步骤见安装包内的安装说明及 Release 附件 `INSTALL-MAC.md`。`SHA256SUMS.txt` 可用于校验下载文件是否一致，不等同于 Apple 开发者身份认证。

## 能做什么

0.1.14 将章节删除改为右键操作：右键章节即可删除、批量删除或恢复已删除章节，不再显示独立的“章节管理”入口。选中文字自动展开右侧修改区，不额外调用 AI。

从公开版 0.1.3 升级，还包括与 AI 讨论后规划 1–12 章、确认后批量建章及顺序起草；正文与设定的联动修改预览；修改意见确认记忆；统一每章目标字数；有预算上限的前文和拆书方法检索。删除或改写时清理相关派生记忆，恢复旧章不会自动恢复旧记忆。候选须确认才采用，检索和模型自检并不保证全书无误。

本版本通过离线、模拟浏览器及原生安装包验收，没有使用真实付费模型验收，不保证每种模型均兼容。旧版未完成的批次可能需要重新规划；升级前请导出备份并另存重要候选。

- 本机创建作品、编辑章节、维护 Bible、大纲、人物和故事资料。
- 独立运行，手动写作不依赖网页服务器或联网。
- 自动保存、本地恢复点、JSON 作品备份导入导出。
- 自带 API Key：MiniMax、OpenAI、DeepSeek、通义千问预置官方站点；需要兼容当前接口的文本模型。
- 复用既有 AI 辅助创作流程，原稿须确认后才采用修改。

## 隐私和使用边界

作品默认保存在本机，不自动上传 GitHub 或云端。调用在线 AI 时，本次选定的材料会发送给你配置的模型服务商，费用由你的服务商账户承担。

API Key 独立加密保存；作品文件本身未加密。应用内恢复点和作品位于同一磁盘，不能替代异地备份。完整作品备份包含已保存的作品、记忆、拆书方法及部分候选记录，不含 Key；并非所有临时会话状态都包含在内。通用场景库的个人定制和程序偏好也不是作品备份的一部分。重要正文与候选请另行备份，不要公开上传作品备份。

没有云同步、自动更新、离线模型或后台批量生成队列。应用升级可能重新请求钥匙串权限。请先用测试作品体验，勿将预览版作为重要稿件的唯一存储。

## 反馈

升级：先导出作品备份并退出应用，再下载新版 DMG、替换“应用程序”中的 Margin。数据目录保持不变；不要删除 `Application Support/Margin`。当前无自动更新，旧版本继续在 Releases 中保留。

欢迎通过本仓库 Issues 反馈。请提供系统版本、芯片型号、复现步骤和报错截图；不要发布 API Key、密码、私人正文或包含这些内容的完整日志。
